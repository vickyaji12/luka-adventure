# Luka Adventure

Game browser 2D platformer original yang terinspirasi oleh art direction gambar referensi: langit cerah, pegunungan, kastil, platform rumput, collectible, musuh, pipe, air, dan flag.

## Teknologi
- HTML5
- CSS3
- Vanilla JavaScript
- HTML5 Canvas
- localStorage
- Tidak membutuhkan backend, framework, Node.js, atau database.

## Fitur
- Main menu
- World 1-1 playable
- Side scrolling camera
- Parallax background
- Player movement + jump + gravity
- Platform collision
- Coins
- 3 Stars
- Walker, flyer, turtle, plant enemies
- Stomp enemy
- Damage, invincibility, 5 lives
- Checkpoints
- Question blocks
- Coin / Star / Shield rewards
- Pipes
- Water hazards
- Finish flag
- Timer
- Pause
- Game Over
- Level Complete
- Basic Level Select
- Keyboard + mobile touch controls
- localStorage save
- Sound effects via Web Audio API
- Responsive display

## Cara menjalankan
1. Extract ZIP.
2. Buka `index.html` langsung di browser modern, atau gunakan Live Server.
3. Klik **PLAY GAME**.

## Kontrol
- A / Arrow Left = kiri
- D / Arrow Right = kanan
- Space / W / Arrow Up = lompat
- Esc = pause
- Mobile: tombol kiri, kanan, dan lompat.

## Deployment
Folder ini adalah static site. Upload seluruh folder ke:
- GitHub Pages
- Cloudflare Pages
- Netlify
- Vercel
- hosting static biasa

Tidak perlu build command.

## Catatan aset
Game ini menggunakan gambar yang digambar secara prosedural dengan Canvas sehingga bisa langsung dimainkan tanpa download aset eksternal. Karakter, musuh, logo, dan desain game dibuat orisinal; gambar referensi dipakai sebagai arahan visual, bukan disalin sebagai aset game.
